# ShopSphere

ShopSphere is a Java-based e-commerce web application developed as a 3rd year Java project.

## Technologies Used

- Java 17
- Maven
- MySQL
- Apache Tomcat 11
- Jakarta Servlet
- JSP
- HTML
- CSS
- JavaScript
- BCrypt

## Features

- User Registration and Login
- Product Catalog
- Shopping Cart
- Checkout
- Order Placement
- My Orders
- Admin Dashboard
- Admin Product Management
- Admin Order Management
- Order Status Management
- MySQL Database Integration

## Project Structure

- src/main/java - Java source code
- src/main/webapp - JSP, CSS and JavaScript files
- database - MySQL database script
- pom.xml - Maven configuration

## Database

The database script is available in:

database/shopsphere.sql

## How to Run

1. Install Java 17.
2. Install MySQL.
3. Install Apache Tomcat 11.
4. Import database/shopsphere.sql into MySQL.
5. Configure the database environment variables.
6. Build the project using Maven.
7. Deploy the generated WAR file to Tomcat.
8. Open the application in a browser.
